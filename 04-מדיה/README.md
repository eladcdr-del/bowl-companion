# מדיה

תמונות, סרטונים, לוגו ותבניות. התיקייה ריקה כרגע. הקבצים הגדולים חיים היום ב־OneDrive (רק 5GB), אז כאן שומרים בעיקר **נכסים קבועים** וקבצים קטנים.

## מבנה מוצע

```
04-מדיה/
  לוגו/           ← קבצי הלוגו (שקוף, על שמנת, על מרווה)
  שקופיות-סיום/   ← שקופית הסיום המלאה, ושקופית לוגו בלבד
  תבניות/         ← תבניות Canva או תמונות דוגמה לכל תבנית שמורה
  תמונות/
    סטודיו/       ← החלל, הנוף, הכלים
    נאיה/         ← דיוקנאות מאושרים
    קערות/        ← תמונות מוצר
  שוברים/         ← השובר המעוצב וגרסת הצימרים
```

## שמות קבצים

`תאריך_מוצר_תיאור.סיומת`, למשל `2026-11-25_קורס_ריל-הזמנה-ינואר.mp4`.

## כללים

- תמונה של משתתפת נכנסת רק אם היא אישרה.
- סרטון עם מוזיקה מאינסטגרם לא נשמר כאן.
- קבצים מעל 50MB נשארים ב־OneDrive, וכאן נשמר רק קישור או תיאור.

## חומרים שקיימים ב־OneDrive

תיקיית "להעלאה" (חומרים מהטלפון) ותיקיית "סרטונים מוכנים" (כל תוצר בתיקייה משלו).
